# #120 Word Guess

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

A five-letter word guessing game (generic name; original word lists, look and texts) in English
and Spanish. `words.ts` (answer and accepted-word lists), `engine.ts` (marks, hard mode, play,
candidates, the solver's guess, save validation), `ai.ts`, `ai-adapter.ts`, `WordGame.tsx` +
`WordGame.module.css`, `HowToPlay.tsx`, `i18n.ts`, `sounds.ts`, `manifest.ts`,
`assets/preview.svg`, `tests/`.
