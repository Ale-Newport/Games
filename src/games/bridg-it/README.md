# #070 Gale (catalog entry "Bridg-It")

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

The catalog name is a trademark, so the game is shown under its generic name, Gale. Self-contained
module: `engine.ts` (interleaved dot grids, one bridge per slot, connection check), `ai.ts`
(Shannon's resistance evaluation solved as a linear circuit, alpha-beta), `ai-adapter.ts`,
`GaleBoard.tsx`, `Game.tsx`, `HowToPlay.tsx`, `i18n.ts`, `manifest.ts`, `assets/preview.svg`,
`tests/`.
