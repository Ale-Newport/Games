# #145 Ludo

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

Classic Ludo on the cross-board race core in `../shared/cross/` (`geometry.ts` the board for any
arm length, `race.ts` the rules engine with options, `heuristic.ts` the computer players,
`CrossBoard.tsx` and `RaceTable.tsx` the table, strings, sounds), shared with Parchís and Pachisi.
Here: `engine.ts` (Ludo's rule options), `ai.ts`, `ai-adapter.ts`, `Game.tsx`, `HowToPlay.tsx`,
`i18n.ts`, `manifest.ts`, `assets/preview.svg`, `tests/`.
