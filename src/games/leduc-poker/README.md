# #092 Leduc Poker

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

Self-contained module: `engine.ts` (six cards, two betting rounds, a match to the last chips,
replay validation), `cfr-game.ts` (one hand as a CFR tree and the information-set key),
`strategy.ts` (the Nash equilibrium table generated by `tools/solve-leduc.ts`), `ai.ts` (Nash and
two hand-written strategies), `ai-adapter.ts` (one hand per episode), `Game.tsx` (the table
definition), `HowToPlay.tsx`, `i18n.ts`, `manifest.ts`, `assets/preview.svg`, `tests/`. Solver:
`src/ai/agents/cfr.ts`; table: `src/games/shared/heads-up-poker/`.
