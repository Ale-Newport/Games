# #011 Reversi 6×6

Reversi on a 6×6 board. Full spec: [GAME_SPEC.md](GAME_SPEC.md). Built entirely on the shared
Reversi family (`src/games/shared/reversi/`, see #010's README); this module only sets the size,
tunes the agent levels for the small board, and defines its own strings, art and achievements.
