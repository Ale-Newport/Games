# #130 Color Links (Flow)

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

A Numberlink-family path puzzle under a generic name, with generated puzzles. `engine.ts` (the
generator, drawing rules, state), `ai.ts`, `ai-adapter.ts`, `LinkGame.tsx` + `Links.module.css`
(SVG paths over the grid), `HowToPlay.tsx`, `i18n.ts`, `sounds.ts`, `manifest.ts`,
`assets/preview.svg`, `tests/`.
