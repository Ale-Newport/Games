# #143 Royal Game of Ur

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

The Mesopotamian race game with Irving Finkel's rules. `engine.ts` (paths, throws, moves,
captures, rosettes), `search.ts` (evaluation, greedy and expectiminimax), `match.ts` (turns, extra
throws, replay validation), `ai.ts`, `ai-adapter.ts`, `UrTable.tsx` + `Ur.module.css`,
`HowToPlay.tsx`, `i18n.ts`, `sounds.ts`, `manifest.ts`, `assets/preview.svg`, `tests/`.
