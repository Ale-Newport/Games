# #013 International Draughts

FMJD international draughts on 10×10. Full spec: [GAME_SPEC.md](GAME_SPEC.md). Built on the
shared draughts family (`src/games/shared/draughts/`, see #012's README) with the `INTERNATIONAL`
variant (men capture backward, flying kings, majority capture, crowning only at the end of a move,
FMJD draw counts). This module sets colors (White moves first), levels, strings, art and
achievements.
