# #121 Hangman

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

The classic letter-guessing word game with original word lists and drawing. `words.ts` (six
categories in English and Spanish), `engine.ts` (levels, guesses, typed words, fitting words, the
solver's letter, save validation), `ai.ts`, `ai-adapter.ts`, `HangmanGame.tsx` +
`Hangman.module.css` (SVG drawing), `HowToPlay.tsx`, `i18n.ts`, `sounds.ts`, `manifest.ts`,
`assets/preview.svg`, `tests/`.
