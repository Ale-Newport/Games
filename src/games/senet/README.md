# #144 Senet

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

The ancient Egyptian race game with Timothy Kendall's reconstructed rules. `engine.ts` (the S-shaped
route, throw sticks, swaps, protection and blockades, the houses 26–30), `search.ts` (evaluation,
greedy and expectiminimax), `match.ts` (turns, extra throws, replay validation), `ai.ts`,
`ai-adapter.ts`, `SenetTable.tsx` + `Senet.module.css`, `HowToPlay.tsx`, `i18n.ts`, `sounds.ts`,
`manifest.ts`, `assets/preview.svg`, `tests/`.
