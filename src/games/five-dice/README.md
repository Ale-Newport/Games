# #149 Five Dice

Full spec: [GAME_SPEC.md](GAME_SPEC.md).

The scorecard dice classic under a generic name, on the shared scorecard core in
`../shared/scorecard/` (`turn.ts` the exact turn planner, `game.ts` state and actions, `planner.ts`
the computer players, `ScorecardTable.tsx` the table, strings, sounds), shared with Generala.
Here: `engine.ts` (the boxes, scoring, bonuses, joker rule, the planner's box values), `ai.ts`,
`ai-adapter.ts`, `Game.tsx`, `HowToPlay.tsx`, `i18n.ts`, `manifest.ts`, `assets/preview.svg`, `tests/`.
